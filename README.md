# Abysmal Fate — Ludum Dare 57

2D roguelike made solo in 48 hours for Ludum Dare 57 (theme: Depths).

**Stack:** C++, Raylib <br>
**Compiler:** MSVC <br>
**Time:** 48 hours

### What I built
- Incremental level generation
- Random targeting enemy behavior
- All game assets

### What I learned
First Raylib project — learned texture management, 
game loop architecture, and input handling under 48-hour time pressure.
